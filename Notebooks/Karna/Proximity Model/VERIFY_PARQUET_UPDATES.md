# verify_parquet.py Updates

## Summary
Updated `verify_parquet.py` to align with the new `ProximityModel.py` implementation (21-step pipeline).

## Changes Made

### 1. Expected Columns List (Lines ~250-290)
**Added new columns:**
- `bearing` - Full 360° bearing (in addition to `normalized_bearing`)
- `public_data_id_start_end_nodes` - Government intersection node IDs
- `oneway_bicycle` - Street-level bicycle oneway attribute

**Street Features (NEW):**
- `street_feature_types`
- `public_data_id_street_feature`
- `street_feature_geometry`
- `street_feature_geometry_projected`

**Sidewalk Features (NEW):**
- `sidewalk_{side}_feature_ids`
- `sidewalk_{side}_feature_types`
- `public_data_id_sidewalk_{side}_feature`
- `sidewalk_{side}_feature_geometry`
- `sidewalk_{side}_feature_geometry_projected`

**Bikeway Features (NEW):**
- `bikeway_{side}_{n}_feature_ids`
- `bikeway_{side}_{n}_feature_types`
- `public_data_id_bikeway_{side}_{n}_features`
- `bikeway_{side}_{n}_feature_geometry`
- `bikeway_{side}_{n}_feature_geometry_projected`

**Bikeway Lane 2 Support:**
- `bikeway_{side}_2_id`
- `bikeway_{side}_2_block_id` (lowercase 'id' to match schema)
- `public_data_id_bikeway_{side}_2`
- `bikeway_{side}_2_type`
- `bikeway_{side}_2_surface`
- `bikeway_{side}_2_permitted`
- `bikeway_{side}_2_width`
- `bikeway_{side}_2_incline`

**Curb Ramp Attributes:**
- `public_data_id_sidewalk_{side}_curbramp_{slot}_{pos}` - Government ramp IDs
- `sidewalk_{side}_curbramp_{slot}_{pos}_returnposition` - Position on return

**Crosswalk Attributes:**
- `public_data_id_crosswalk_{slot}` - Government crosswalk IDs
- All crosswalk attribute columns (controlled, marked, markings, signals, etc.)

**Geometry Columns:**
- `start_node_geometry` - WKB bytes for start node
- `end_node_geometry` - WKB bytes for end node
- `bikeway_left_2_geometry` - Lane 2 geometry
- `bikeway_right_2_geometry` - Lane 2 geometry

### 2. Geometry Column Verification (Lines ~310-330)
**Added to verification list:**

## Schema Alignment

The updated verification script now checks for **206 columns** matching the ProximityModel.py schema:

### Column Categories:
1. **Block & Street** (18 columns): IDs, attributes, features
2. **Sidewalks** (88 columns): 2 sides × (8 base + 36 curb ramps + 5 features)
3. **Crosswalks** (30 columns): 2 slots × 15 attributes each
4. **Bikeways** (60 columns): 2 sides × 2 lanes × (8 base + 5 features + buffered flag)
5. **Geometries** (10 columns): All WKB bytes

## Key Features Verified

### 1. Curb Ramp Trustworthiness
- Verifies that when `curbramp_trustworthy=False`, no government ramp IDs are present
- Checks for default (model-generated) curb ramps
- Validates curb return geometries

### 2. Feature Geometry
- Validates MultiPoint geometries for features
- Checks both original and projected feature geometries
- Verifies feature type and ID lists

### 3. Block Structure
- Validates block ID tuples (left, right)
- Checks block side labels (e.g., "1_2_3_N")
- Verifies block node flags

### 4. Bearing Normalization
- Checks `bearing` in [0, 360)
- Checks `normalized_bearing` in [0, 180)

## Compatibility

The updated script is fully compatible with parquet files generated by:
- `ProximityModel.py` (new 21-step pipeline)
- Both `curbramp_trustworthy=True` and `curbramp_trustworthy=False` configurations
